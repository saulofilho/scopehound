O farejador que nunca sai do escopo.

Um agente de IA que segue o faro, forma hipóteses e chama ferramentas — mas o escopo e as permissões vivem fora do modelo. Nenhum prompt os burla. Inspirado na lógica do Burp AT.

01 · o método

O modelo pede. A política decide. A ferramenta executa.

A cada passo, uma camada de guardrails separada do modelo valida escopo, DNS, orçamento e permissão antes de qualquer requisição sair. É a mesma ideia do Burp AT: a regra não mora no prompt.

02 · o faro

Tudo que um detetive precisa — dentro da cerca.

Explorando — C:\scopehound\recursos_□×
EndereçoC:\scopehound\recursos

Escopo que não se burla

Host, porta, path e método autorizados. Conecta no IP já validado (DNS pinning), bloqueia metadados de nuvem e rede interna. Fora do escopo, nada sai.

Skills com metodologia

IDOR, content discovery e race condition prontas. A skill carrega o roteiro e restringe as ferramentas àquele trabalho.

Contexto do caso

Proxy de captura, importação de HAR e do XML do Burp, e um site map que normaliza /api/users/{id} e marca parâmetros numéricos.

Aprovações no seu ritmo

Manual, Smart ou Autônomo. Aprovar uma vez, para a sessão, sempre, rejeitar ou redirecionar. A pausa sobrevive a reinícios.

/goal e subagentes

Dê um objetivo e o agente o persegue por vários passos; para investigações amplas, divide o trabalho em subagentes com orçamento próprio.

Local ou servidor

Rode na sua máquina com SQLite, ou suba para o time com Postgres, login via SSO, papéis e mascaramento de dados sensíveis.

03 · a pista

Uma pista só vira achado quando a prova bate.

O agente registra leads e reexecuta a prova de conceito para confirmar. Nada de achado sem evidência reproduzível.

05 · ao trabalho

Solte o farejador.

Python 3.12+ e uv. Aponte só para sistemas seus ou com autorização por escrito.

Assistente de instalação do scopehound×

Bem-vindo ao assistente do scopehound

Siga os passos abaixo para configurar o escopo e soltar o farejador no seu laboratório.

REM instale e configure o escopo
git clone https://github.com/saulofilho/scopehound
cd scopehound && uv sync
cp scope.example.yaml scope.yaml

REM confira o alvo sem enviar nada
uv run scopehound check http://localhost:3000 -s scope.yaml

REM crie o projeto e converse com o agente
uv run scopehound project create lab -s scope.yaml
uv run scopehound chat lab --mode smart

Aviso de segurança×

Uso autorizado apenas. O arquivo de escopo é o contrato: o que não está nele é bloqueado antes de qualquer I/O. Aponte o scopehound só para sistemas que você possui ou tem permissão escrita para testar.
